# Your RHCE exam lab is being built

Nothing to type. If VS Code asks whether you trust this folder, click **Trust**.

The build runs in the terminal panel at the bottom and takes about 15 to 20 minutes the first time.
When it finishes, the **RHCE Lab Console** opens in a new tab:
control-node and node-1 to node-4, each with Terminal, Start, Stop and Reboot buttons,
plus Prepare and Grade buttons for Exam A and Exam B.

- Console didn't open? Type `lab console` in the terminal.
- Set your idle timeout to 4 hours at github.com/settings/codespaces so the lab doesn't stop while you read a task.
- Done for the day? Stop the codespace at github.com/codespaces so it doesn't use your free hours.
