# RHCE EX294 practice lab

One click builds a full EX294 practice fleet in a free GitHub Codespace:
**control-node** plus **node-1 to node-4** (web1, web2, util1 and stor1, a real Rocky Linux 9 virtual machine with SELinux and LVM).

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/it-waves/rhce-lab?quickstart=1)

1. Click the button and sign in to GitHub (a free account is enough).
2. Wait about 15 minutes. The **RHCE Lab Console** opens by itself.
3. Use the console's buttons: Terminal, Start, Stop and Reboot for each node, and Prepare / Grade for Exam A and Exam B.

Free GitHub accounts include 60 hours of Codespaces a month. Nothing is charged unless you add a payment method.
Set your idle timeout to 4 hours (github.com/settings/codespaces) so the lab doesn't stop while you read a task.
Stop the codespace when you finish for the day, and delete it when you're done.

The exams, timer and scoring are on the practice exam page: https://rhce-practice-exam.pages.dev
Part of the free RHCE course on DevOps Simplified.
